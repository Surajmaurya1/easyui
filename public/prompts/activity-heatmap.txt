## Usage

Import path and example from component metadata:

```tsx
import { ActivityHeatmap } from "@/components/ui/activity-heatmap";

const data = [
  { date: "2026-10-18", value: 3 },
  { date: "2026-10-19", value: 9 },
  { date: "2026-10-20", value: 5 },
  { date: "2026-10-21", value: 12 },
];

export function Demo() {
  return (
    <div className="w-full max-w-3xl rounded-2xl bg-white p-5 dark:bg-neutral-950">
      <ActivityHeatmap data={data} weekStart={1} unit="contributions" />
    </div>
  );
}
```

Declared props:
- `mode` ("calendar" | "hours"); default: "calendar" — One cell per day or a weekday-by-hour grid
- `data` (HeatDay[]) — Calendar data as { date: "YYYY-MM-DD" | Date, value: number } entries
- `matrix` (number[][]) — Hours-mode matrix with 7 rows (weekdays) and 24 columns (hours)
- `rowLabels` (string[]); default: ["Mon", … , "Sun"] — Row names used in hours mode
- `weeks` (number); default: 53 — Maximum number of weeks to show in calendar mode
- `endDate` (string | Date) — Last day displayed; defaults to the latest date in the data
- `weekStart` (0 | 1); default: 0 — First day of the week: 0 for Sunday, 1 for Monday
- `color` (string); default: "#34d399" — Base color mixed into the activity levels
- `unit` (string); default: "contributions" — Plural noun used in the summary and tooltip
- `minCell` (number); default: 11 — Smallest cell size before calendar columns are dropped
- `animated` (boolean); default: true — Enables the staggered cell entrance animation
- `ariaLabel` (string); default: auto-generated — Accessible description for the heatmap image role
- `className` (string); default: "" — Additional CSS classes for the heatmap wrapper
