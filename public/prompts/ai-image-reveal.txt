## Usage

Import path and example from component metadata:

```tsx
import { AIImageReveal } from "@/components/ui/AIImageReveal";

const imageUrl = "https://images.unsplash.com/photo-1470770841072-f978cf4d019e?auto=format&fit=crop&w=900&q=85";

export function Demo() {
  return (
    <AIImageReveal
      src={imageUrl}
      alt="Mountain lake at sunset"
      prompt="A quiet lake beneath the mountains"
      aspectRatio={4 / 3}
    />
  );
}
```

Declared props:
- `src` (string | null); default: undefined — Public image URL to reveal; omit while generating.
- `alt` (string) — Alternative text for the finished image.
- `generating` (boolean); default: derived from src — Force the generating state while an image URL is present.
- `aspectRatio` (number); default: 1 — Width divided by height of the image frame.
- `prompt` (string) — Optional caption displayed below the image.
- `generatingLabel` (string); default: Generating… — Status pill label while waiting or gathering.
- `colors` (string[]) — Optional particle palette as hex colors.
- `density` (number); default: 1 — Particle density multiplier from 0.4 to 2.
- `duration` (number); default: 3.2 — Reveal duration in seconds.
- `crossOrigin` ("anonymous" | "use-credentials" | ""); default: "anonymous" — Cross-origin mode used when loading the image.
- `onReveal` (() => void) — Called after the image reveal completes.
- `onImageError` (() => void) — Called if the image URL cannot be loaded.
- `ref` (AIImageRevealHandle) — Exposes replay() to play the reveal again.
