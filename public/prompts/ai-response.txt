## Usage

Import path and example from component metadata:

```tsx
import { AIResponse, AIResponseHeader, AIResponseContent, AIResponseSources, AIResponseActions } from "@/components/ui/ai-response";

export function Demo() {
  return (
    <AIResponse
      status="complete"
      modelName="Claude 3.7 Sonnet"
      content="Here is a verified solution using **EasyUI** motion tokens:\n\n```typescript\nimport { motionTransitions } from '@/lib/motion-tokens';\n\nexport const config = motionTransitions.springSnappy;\n```"
      sources={[
        { id: 1, title: "EasyUI Motion Tokens", url: "https://easyui.pro/docs" },
        { id: 2, title: "Framer Motion Spring Spec", url: "https://www.framer.com/motion/" }
      ]}
      onRegenerate={() => console.log('Regenerating...')}
    />
  );
}
```

Declared props:
- `content` (string); default: '' — Markdown or plain text response generated by the AI model
- `status` ('idle' | 'generating' | 'streaming' | 'complete' | 'error' | 'cancelled'); default: 'complete' — Current generation lifecycle state
- `modelName` (string); default: 'EasyAI 2.0' — Model identifier badge displayed in header
- `sources` (AIResponseSource[]); default: [] — Array of citations or references referenced in the answer
- `onRegenerate` (() => void); default: undefined — Optional callback fired when the user clicks the regenerate button
- `onFeedback` ((type: 'like' | 'dislike') => void); default: undefined — Optional callback fired when the user provides quality feedback
- `children` (ReactNode); default: undefined — Optional custom composition using AIResponse compound subcomponents
- `className` (string); default: undefined — Custom Tailwind class names for styling overrides
