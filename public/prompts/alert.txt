## Usage

Import path and example from component metadata:

```tsx
import { Alert, AlertTitle, AlertDescription } from "@/components/ui/alert";

<Alert tone="danger" dismissible onDismiss={() => handleDismiss()}>
  <AlertTitle>Payment failed</AlertTitle>
  <AlertDescription>Your card was declined. Please try another card.</AlertDescription>
</Alert>

<Alert tone="success">
  <AlertTitle>Changes saved successfully</AlertTitle>
</Alert>
```

Declared props:
- `tone` ('neutral' | 'info' | 'success' | 'warning' | 'danger'); default: 'neutral' — Color tone and severity semantic level
- `icon` (React.ReactNode | false); default: undefined — Custom icon element, or false to suppress icon
- `dismissible` (boolean); default: false — Renders an interactive close button
- `onDismiss` (() => void); default: undefined — Callback invoked after the exit collapse animation completes
- `action` (React.ReactNode); default: undefined — Optional right-hand action element (e.g. action button)
- `className` (string); default: undefined — Additional CSS classes for the alert container
