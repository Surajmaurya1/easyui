## Usage

Import path and example from component metadata:

```tsx
import { AnimatedNumber } from "@/components/ui/animated-number";

export function Demo() {
  const [revenue, setRevenue] = useState(12450);

  return (
    <div className="text-3xl font-bold">
      <AnimatedNumber value={revenue} prefix="$" useGrouping />
    </div>
  );
}
```

Declared props:
- `value` (number); default: 0 — The numeric target value to morph towards
- `decimals` (number); default: 0 — Number of decimal places to preserve
- `prefix` (string); default: '' — Text or currency prepended to number (e.g. "$")
- `suffix` (string); default: '' — Text or unit appended to number (e.g. "%", "ms")
- `useGrouping` (boolean); default: true — Formats with comma separators
- `compact` (boolean); default: false — Formats using compact abbreviations (K, M, B)
- `stiffness` (number); default: 170 — Spring transition stiffness
- `damping` (number); default: 22 — Spring transition damping
