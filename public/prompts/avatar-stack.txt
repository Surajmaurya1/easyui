Install and integrate the EasyUI Avatar Stack component into my project.

## Usage

Import path and example from component metadata:

```tsx
<AvatarStack
  size="lg"
  overlap="lg"
  avatars={[
    { id: 1, src: 'https://i.pravatar.cc/150?img=1', alt: 'John Doe' },
    { id: 2, src: 'https://i.pravatar.cc/150?img=2', alt: 'Sarah Smith' },
    { id: 3, src: 'https://i.pravatar.cc/150?img=3', alt: 'Mike Johnson' },
    { id: 4, src: 'https://i.pravatar.cc/150?img=4', alt: 'Emily Davis' },
    { id: 5, src: 'https://i.pravatar.cc/150?img=5', alt: 'Alex Wilson' },
    { id: 6, src: 'https://i.pravatar.cc/150?img=6', alt: 'Chris Brown' },
  ]}
/>
```

Declared props:
- `avatars` (AvatarStackItem[]); default: [] — Array of avatar objects with id, src, alt, and fallback
- `max` (number); default: 5 — Maximum visible avatars before showing the +N counter
- `size` ('sm' | 'md' | 'lg' | 'xl'); default: 'lg' — Dimension variant for each avatar circle
- `overlap` ('sm' | 'md' | 'lg'); default: 'md' — Negative margin overlap amount between adjacent avatars
- `showCount` (boolean); default: true — Whether to show the +N counter badge for overflow items
- `showTooltip` (boolean); default: true — Whether to show a floating tooltip label on hover
