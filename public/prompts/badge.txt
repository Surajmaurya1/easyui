## Usage

Import path and example from component metadata:

```tsx
import { Badge } from "@/components/ui/badge";

<Badge>Draft</Badge>
<Badge tone="success" dot pulse>Live</Badge>
<Badge variant="solid" tone="danger">{unreadCount}</Badge>
<Badge variant="outline" tone="warning" onRemove={() => removeTag()}>Tag</Badge>
```

Declared props:
- `variant` ('soft' | 'solid' | 'outline'); default: 'soft' — Visual style of the badge
- `tone` ('neutral' | 'success' | 'warning' | 'danger'); default: 'neutral' — Color tone of the badge
- `dot` (boolean); default: false — Displays a leading status indicator dot
- `pulse` (boolean); default: false — Adds a soft animated pulse ring to the status dot
- `onRemove` (() => void); default: undefined — Callback enabling dismissible chip mode with an × icon
- `children` (React.ReactNode); default: undefined — Badge contents (strings & numbers auto-roll on change)
