## Usage

Import path and example from component metadata:

```tsx
import { BarChart } from "@/components/ui/bar-chart";

const data = [
  { label: "Jan", web: 2400, mobile: 1700 },
  { label: "Feb", web: 2800, mobile: 1950 },
  { label: "Mar", web: 3150, mobile: 2120 },
];

const series = [
  { key: "web", label: "Web" },
  { key: "mobile", label: "Mobile" },
];

export function Demo() {
  return (
    <div className="w-full max-w-2xl rounded-2xl bg-white p-5 dark:bg-neutral-950">
      <BarChart data={data} series={series} variant="grouped" height={260} />
    </div>
  );
}
```

Declared props:
- `data` (BarDatum[]) — Categories to render; each row needs a label plus one numeric key per series
- `series` (BarSeries[]) — Series definitions with a data key, display label, and optional color
- `variant` ("grouped" | "stacked"); default: "grouped" — Places bars side by side or stacks them on top of each other
- `height` (number); default: 260 — Height of the chart area in pixels
- `formatValue` ((n: number) => string); default: Intl.NumberFormat — Formats values shown in tooltips and the accessible data table
- `formatTick` ((n: number) => string); default: compact Intl.NumberFormat — Formats the y-axis tick labels
- `showLegend` (boolean); default: true — Shows the interactive series legend when more than one series exists
- `animated` (boolean); default: true — Enables entrance and bar morph animations (disabled for reduced motion)
- `ariaLabel` (string); default: auto-generated — Accessible description for the chart image role
- `className` (string); default: "" — Additional CSS classes for the chart wrapper
