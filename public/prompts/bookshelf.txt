## Usage

Import path and example from component metadata:

```tsx
import Bookshelf, { type BookItem } from "@/components/ui/Bookshelf";

const books: BookItem[] = [
  { id: "gatsby", title: "The Great Gatsby", author: "F. Scott Fitzgerald", color: "#1f3d36" },
];

export function Demo() {
  return <Bookshelf books={books} />;
}
```

Declared props:
- `books` (BookItem[]); default: required — Books to display, each with an id, title, author, and cover color.
- `openId` (string | null); default: undefined — Optional controlled ID of the currently open book.
- `onOpenChange` ((id: string | null, book?: BookItem) => void); default: undefined — Called when the open book changes.
- `onRead` ((book: BookItem) => void); default: undefined — Called by the default Read action.
- `actions` ((book: BookItem, close: () => void) => ReactNode); default: undefined — Replaces the default Read and Close actions.
- `ariaLabel` (string); default: Bookshelf — Accessible label for the book list.
- `className` (string); default: undefined — Additional classes for the bookshelf root.
