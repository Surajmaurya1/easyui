## Usage

Import path and example from component metadata:

```tsx
import Link from "next/link";
import { Home } from "lucide-react";
import { Breadcrumb } from "@/components/ui/breadcrumb";

<Breadcrumb
  as={Link}
  items={[
    { label: "Home", href: "/", icon: <Home className="size-4" /> },
    { label: "Projects", href: "/projects" },
    { label: "EasyUI", href: "/projects/easyui" },
    { label: "Components", href: "/projects/easyui/components" },
    { label: "Breadcrumb" }, // Current page (no href needed)
  ]}
/>
```

Declared props:
- `items` (BreadcrumbItem[]); default: undefined — Array of breadcrumb items with label, href, and optional icon
- `separator` ('chevron' | 'slash'); default: 'chevron' — Separator style between breadcrumb items
- `maxItems` (number); default: 4 — Collapse the middle items when length exceeds this number
- `as` (React.ElementType); default: 'a' — Custom link component (e.g. Next.js Link)
- `className` (string); default: undefined — Additional CSS classes for the nav container
