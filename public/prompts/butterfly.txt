## Usage

Import path and example from component metadata:

```tsx
import { Butterfly } from "@/components/ui/Butterfly";

export function Demo() {
  return (
    <div className="flex flex-col items-center gap-4">
      <Butterfly variant="split" behavior="natural" size={380} />
    </div>
  );
}
```

Declared props:
- `variant` ("split" | "lines" | "ascii"); default: "split" — Render mode combining line-art and ASCII, all vector lines, or all ASCII text
- `asciiSide` ("right" | "left"); default: "right" — Which side renders as ASCII characters when variant is "split"
- `behavior` ("natural" | "flap" | "glide" | "perch"); default: "natural" — Flight mode: cycles naturally or locks to flap, glide, or perch
- `size` (number); default: 380 — Maximum width in pixels; shrinks smoothly to fit its container
- `speed` (number); default: 1 — Wing-beat and flight speed multiplier
- `float` (boolean); default: true — Enables gentle ambient drift and tilt motion
- `paused` (boolean); default: false — Pauses the animation loop while keeping the current frame
- `colors` ([string, string, string?]); default: undefined — Up to three CSS colors for the line and text gradient
- `interactive` (boolean); default: true — Hovering or tapping startles the butterfly into a brief flutter
- `ariaLabel` (string); default: "A butterfly slowly beating its wings" — Accessible label for the butterfly visual
- `className` (string); default: "" — Additional CSS classes merged into the outer container
