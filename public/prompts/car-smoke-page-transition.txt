## Usage

Import path and example from component metadata:

```tsx
import { CarSmokePageTransition } from "@/components/ui/car-smoke-page-transition";

export function Demo() {
  return (
    <CarSmokePageTransition
      onTransitionComplete={() => {
        // Navigate to new page after animation completes
        window.location.href = "/about";
      }}
    >
      <button className="bg-[#FAFAFA] text-[#050505] hover:bg-white px-4 py-2 rounded-md font-medium transition-colors">
        Start Journey
      </button>
    </CarSmokePageTransition>
  );
}
```

Declared props:
- `direction` ('left-to-right' | 'right-to-left'); default: 'left-to-right' — Direction of car travel
- `carDuration` (number); default: 700 — Duration of car crossing animation in milliseconds
- `carDelay` (number); default: 0 — Delay before car starts moving in milliseconds
- `carSize` ('sm' | 'md' | 'lg'); default: 'md' — Size of the car (affects scale)
- `smokeDensity` ('off' | 'low' | 'medium' | 'high'); default: 'medium' — Density of smoke particles emitted
- `smokeLifetime` (number); default: 1200 — Lifetime of smoke particles in milliseconds
- `showSpeedLines` (boolean); default: true — Whether to show speed lines effect behind the car
- `pageTransitionDelay` (number); default: 550 — Delay before page transition overlay starts in milliseconds
- `pageTransitionDuration` (number); default: 350 — Duration of page transition overlay fade in milliseconds
- `resetDelay` (number); default: 300 — Delay before resetting to idle after transition completes in milliseconds
- `onTransitionComplete` (() => void); default: undefined — Callback fired when transition completes (call navigate() here)
- `children` (ReactNode); default: undefined — The trigger element (typically a Button)
- `className` (string); default: undefined — Additional Tailwind classes merged into the root
