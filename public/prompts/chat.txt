## Usage

Import path and example from component metadata:

```tsx
import { Chat, type ChatMessageItem } from "@/components/ui/chat";

export function Demo() {
  const messages: ChatMessageItem[] = [
    { id: '1', role: 'user', content: 'Can you show me how to style EasyUI tables?', timestamp: '10:40 AM' },
    { id: '2', role: 'assistant', content: 'Certainly! EasyUI tables use the semantic --border and --surface tokens.', timestamp: '10:41 AM' },
  ];

  return (
    <Chat
      messages={messages}
      onSendMessage={(text) => console.log('Send:', text)}
    />
  );
}
```

Declared props:
- `messages` (ChatMessageItem[]); default: [] — Array of chat message records including role, content, author, and attachments
- `onSendMessage` ((content: string, attachments?: ChatAttachment[]) => void); default: undefined — Callback fired when the user submits a message via composer
- `isGenerating` (boolean); default: false — Disables composer and shows loading status while the assistant is synthesizing an answer
- `threads` (ChatConversationThread[]); default: undefined — Optional list of historical conversations displayed in the sidebar
- `activeThreadId` (string); default: undefined — ID of the currently selected conversation thread
- `onSelectThread` ((threadId: string) => void); default: undefined — Callback fired when a user selects a thread from the history sidebar
- `onNewChat` (() => void); default: undefined — Callback fired when the user clicks the New Conversation button
- `onClearChat` (() => void); default: undefined — Callback fired when the user clicks the clear chat history button
- `className` (string); default: undefined — Custom Tailwind class names for styling overrides
