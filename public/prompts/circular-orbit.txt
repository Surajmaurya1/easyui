## Task

Install and integrate the EasyUI Circular Orbit component into my project.

A circular gallery of image tiles orbiting around a centered title. All motion runs on a single MotionValue driven by useAnimationFrame, so no React renders per frame.

## Usage

Import path and example from component metadata:

```tsx
import { CircularOrbit } from "@/components/ui/circular-orbit";

export function Demo() {
  return (
    <div className="w-full max-w-3xl mx-auto rounded-2xl border border-[#1F1F1F] overflow-hidden">
      <CircularOrbit
        title="Push"
        speed={0.00022}
        radius={240}
        pauseOnHover
      />
    </div>
  );
}
```

Declared props:
- `items` (OrbitItem[]); default: 14 Unsplash tiles — Tiles to place around the orbit
- `title` (string); default: 'Push' — Centered headline rendered above the orbit
- `speed` (number); default: 0.00022 — Radians per millisecond. Smaller = slower
- `radius` (number); default: 270 — Pixel radius of the orbit on the desktop layout
- `pauseOnHover` (boolean); default: true — Smoothly stop the orbit when the pointer enters the gallery
- `className` (string); default: undefined — Additional Tailwind classes merged into the section root
