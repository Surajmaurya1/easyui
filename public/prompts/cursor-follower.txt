## Usage

Import path and example from component metadata:

```tsx
import { CursorFollower } from "@/components/ui/cursor-follower";
import { ArrowUpRight } from "lucide-react";

export function Demo() {
  return (
    <CursorFollower size={44}>
      <div className="flex h-full w-full items-center justify-center rounded-full bg-white text-black shadow-lg">
        <ArrowUpRight className="h-4 w-4" />
      </div>
    </CursorFollower>
  );
}
```

Declared props:
- `children` (React.ReactNode); default: undefined — Custom icon, text badge, or React element displayed inside the cursor follower.
- `size` (number); default: 40 — Width and height of the cursor follower in pixels.
- `offsetX` (number); default: 0 — Horizontal offset from the cursor coordinates.
- `offsetY` (number); default: 0 — Vertical offset from the cursor coordinates.
- `stiffness` (number); default: 450 — Spring stiffness controlling how rapidly the follower catches up to the cursor.
- `damping` (number); default: 32 — Spring damping controlling the smoothness and friction of deceleration.
- `mass` (number); default: 0.5 — Spring mass controlling inertia and physical weight.
- `scaleOnMove` (boolean); default: true — Scales the cursor follower slightly while the pointer is in active motion.
- `hideOnLeave` (boolean); default: true — Hides the cursor follower when the pointer leaves the browser window or viewport.
- `className` (string); default: undefined — Optional custom Tailwind CSS utility classes.
