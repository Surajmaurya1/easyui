## Task

Install and integrate the EasyUI Date Picker component into my project.

A date picker (and date range picker) whose popover pops from the trigger edge with a spring, flips above when there is no room below, lands the selection pill, then closes and hands focus back to the trigger.

## Usage

Import path and example from component metadata:

```tsx
import { DatePicker, DateRangePicker } from "@/components/ui/date-picker";

<DatePicker value={date} onChange={setDate} placeholder="Due date" minDate={new Date()} />

<DateRangePicker value={range} onChange={setRange} />
```

Declared props:
- `value` (Date | null | DateRange); default: undefined — Controlled selected value
- `defaultValue` (Date | null | DateRange); default: null — Initial value (uncontrolled)
- `onChange` ((date: Date | null) => void | (range: DateRange) => void); default: undefined — Selection change callback
- `placeholder` (string); default: 'Pick a date' / 'Pick a range' — Trigger placeholder text
- `align` ('start' | 'end'); default: 'start' — Popover alignment relative to the trigger
- `side` ('bottom' | 'top' | 'auto'); default: 'auto' — Popover placement; 'auto' opens downward on mobile and flips on desktop when tight
- `disabled` (boolean); default: false — Disables the trigger
- `className` (string); default: undefined — Additional class for the wrapper (set width, e.g. w-80)
