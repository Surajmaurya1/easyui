## Usage

Import path and example from component metadata:

```tsx
import { DensityLens } from "@/components/ui/density-lens";

export function Demo() {
  return (
    <DensityLens lensSize={160} zoomScale={2}>
      <div className="p-8 bg-[#0C0C0C] rounded-2xl border border-[#222222]">
        <h3 className="text-sm font-semibold text-white">System Architecture</h3>
        <p className="text-xs text-[#808080] mt-2">
          Hover pointer across surface to inspect high-resolution telemetry nodes.
        </p>
      </div>
    </DensityLens>
  );
}
```

Declared props:
- `children` (ReactNode) — Underlying background content being inspected
- `renderLensContent` ((pos: { x: number, y: number, scale: number }) => ReactNode); default: undefined — Custom overlay rendered inside lens
- `lensSize` (number); default: 150 — Diameter/width of lens in pixels
- `lensShape` ('circle' | 'oval' | 'square'); default: 'circle' — Geometric shape of lens
- `zoomScale` (number); default: 2 — Magnification factor
- `showBorder` (boolean); default: true — Renders border and glass glow around perimeter
