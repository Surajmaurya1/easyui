## Usage

Import path and example from component metadata:

```tsx
import { DepthCorridor } from "@/components/ui/depth-corridor";

export function Demo() {
  return (
    <DepthCorridor
      layers={[
        { id: '1', title: 'Edge Telemetry', subtitle: 'Real-time p99 latency', content: <div>12.4ms global response</div> },
        { id: '2', title: 'Cluster Workers', subtitle: 'Serverless nodes', content: <div>64 active workers</div> },
        { id: '3', title: 'Cache Invalidation', subtitle: 'Instant purge API', content: <div>0.4s TTL sync</div> },
      ]}
    />
  );
}
```

Declared props:
- `layers` (DepthLayer[]) — Array of layer objects (id, title, subtitle, content, blurAmount)
- `activeLayerIndex` (number); default: 0 — Controlled active foreground layer index
- `onLayerChange` ((index: number) => void); default: undefined — Layer change event callback
- `perspectiveDepth` (number); default: 1000 — CSS 3D perspective container depth in pixels
- `enableParallax` (boolean); default: true — Enables mouse coordinate responsive 3D tilt
