## Usage

Import path and example from component metadata:

```tsx
import { DonutChart } from "@/components/ui/donut-chart";

const data = [
  { label: "Compute", value: 5240 },
  { label: "Storage", value: 3180 },
  { label: "Bandwidth", value: 2260 },
  { label: "Databases", value: 1610 },
];

export function Demo() {
  return (
    <div className="w-full max-w-md rounded-2xl bg-white p-5 dark:bg-neutral-950">
      <DonutChart
        data={data}
        centerLabel="Total spend"
        formatValue={(value) => `$${value.toLocaleString()}`}
      />
    </div>
  );
}
```

Declared props:
- `data` (DonutDatum[]) — Slices with a label, numeric value, and optional color
- `variant` ("donut" | "semi"); default: "donut" — Renders a full ring or a half-ring gauge
- `size` (number); default: 240 — Largest diameter in pixels; the chart shrinks to fit narrow containers
- `thickness` (number); default: 16 — Stroke width of the ring in pixels
- `centerLabel` (string); default: "Total" — Caption shown above the total in the center
- `formatValue` ((n: number) => string); default: Intl.NumberFormat — Formats center values, slice values, and tooltips
- `showLegend` (boolean); default: true — Shows the interactive slice legend
- `animated` (boolean); default: true — Enables intro and value animations (disabled for reduced motion)
- `ariaLabel` (string); default: auto-generated — Accessible description for the chart image role
- `className` (string); default: "" — Additional CSS classes for the chart wrapper
