## Usage

Import path and example from component metadata:

```tsx
import { DotField } from "@/components/ui/dot-field";

export function Demo() {
  return (
    <div className="relative w-full h-[300px] overflow-hidden rounded-xl bg-[#0A0A0A]">
      <DotField
        dotRadius={1.5}
        dotSpacing={14}
        gradientFrom="rgba(56, 189, 248, 0.35)"
        gradientTo="rgba(168, 85, 247, 0.25)"
      />
    </div>
  );
}
```

Declared props:
- `dotRadius` (number); default: 1.5 — Radius of each individual dot (px)
- `dotSpacing` (number); default: 14 — Spacing between adjacent dots in the grid (px)
- `gradientFrom` (string); default: 'rgba(56, 189, 248, 0.35)' — Start gradient color
- `gradientTo` (string); default: 'rgba(168, 85, 247, 0.25)' — End gradient color
- `className` (string); default: '' — Optional container CSS class
