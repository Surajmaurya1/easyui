## Usage

Import path and example from component metadata:

```tsx
import { DotShader } from "@/components/ui/dot-shader";

export function Demo() {
  return (
    <div className="relative w-full min-h-[500px] rounded-2xl overflow-hidden bg-background border border-border">
      <DotShader
        dotColor="rgba(255, 255, 255, 0.15)"
        accentColor="#00F0FF"
        spacing={24}
        dotSize={1.5}
        cursorRadius={200}
        distortionStrength={0.4}
        maxScale={2.5}
      >
        <div className="min-h-[500px] flex flex-col items-center justify-center text-center p-8">
          <span className="text-xs font-mono uppercase tracking-widest text-cyan-400 mb-2">
            GPU WebGL Shader
          </span>
          <h2 className="text-3xl sm:text-5xl font-bold tracking-tight text-text-primary">
            Interactive Dot Matrix
          </h2>
          <p className="mt-3 text-xs sm:text-sm text-text-secondary max-w-md">
            Move your cursor across the canvas to experience magnetic repulsion and proximity illumination.
          </p>
        </div>
      </DotShader>
    </div>
  );
}
```

Declared props:
- `children` (ReactNode) — Optional content rendered above the interactive dot shader canvas with full clickability
- `dotColor` (string); default: 'rgba(255, 255, 255, 0.15)' — Idle color of the background matrix dots (hex, rgb, or rgba)
- `accentColor` (string); default: '#00F0FF' — Luminous highlight color of dots illuminated by cursor proximity
- `dotSize` (number); default: 1.5 — Base radius in pixels of each individual dot
- `spacing` (number); default: 22 — Distance in pixels between adjacent dots in the grid
- `cursorRadius` (number); default: 180 — Radius in pixels of cursor influence and repulsion
- `distortionStrength` (number); default: 0.35 — Force multiplier of magnetic repulsion away from the cursor (0 to 1)
- `maxScale` (number); default: 2.2 — Maximum scale multiplier of dots at peak cursor proximity
- `waveIntensity` (number); default: 0.25 — Amplitude of ambient idle sinusoidal wave motion
- `speed` (number); default: 1 — Speed multiplier for the ambient background waves
- `interactive` (boolean); default: true — Whether dots react to cursor movements with repulsion and illumination
- `overlay` (boolean); default: true — Enables a soft radial vignette gradient to seamlessly blend container edges
- `className` (string) — Additional CSS classes for container sizing and layout
