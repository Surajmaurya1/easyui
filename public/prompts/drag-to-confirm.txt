## Usage

Import path and example from component metadata:

```tsx
import { DragToConfirm } from "@/components/ui/drag-to-confirm";

export function Demo() {
  return (
    <DragToConfirm
      actionType="delete"
      size="md"
      label="Slide to delete database →"
      confirmedLabel="Database Deleted ✓"
      onConfirm={() => console.log('Destroy action confirmed')}
    />
  );
}
```

Declared props:
- `label` (string); default: 'Slide to confirm' — Action instruction text rendered along track
- `confirmedLabel` (string); default: 'Confirmed ✓' — Text shown when slider locks into completion
- `actionType` ('delete' | 'archive' | 'confirm' | 'submit' | 'unlock' | 'continue'); default: 'confirm' — Action preset style and icon archetype
- `variant` ('default' | 'danger' | 'warning' | 'info' | 'success'); default: undefined — Visual tone variant override
- `size` ('sm' | 'md' | 'lg'); default: 'md' — Slider dimension profile (sm: 40px, md: 48px, lg: 54px)
- `icon` (React.ReactNode); default: undefined — Custom idle state icon rendered inside thumb
- `confirmedIcon` (React.ReactNode); default: undefined — Custom confirmed state icon rendered inside thumb
- `isConfirmed` (boolean); default: undefined — Controlled confirmation state
- `onConfirm` (() => void); default: undefined — Callback triggered upon successful confirmation completion
- `onReset` (() => void); default: undefined — Callback triggered upon slider reset
- `autoResetDelay` (number); default: 2500 — Milliseconds before resetting back to start (0 to disable)
- `haptic` (boolean); default: true — Triggers subtle vibration feedback upon confirmation
- `disabled` (boolean); default: false — Disables slider gesture and interaction
