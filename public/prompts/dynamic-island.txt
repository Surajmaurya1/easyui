## Usage

Import path and example from component metadata:

```tsx
import { DynamicIsland } from "@/components/ui/dynamic-island";

export function Demo() {
  return (
    <DynamicIsland
      name="Suraj Maurya"
      role="Frontend Developer"
      description="Building thoughtful interfaces with React and Next.js."
      statusText="Available for hire"
      socials={{
        github: "https://github.com/Surajmaurya1",
        x: "https://x.com",
        linkedin: "https://linkedin.com",
        instagram: "https://instagram.com",
        email: "mailto:suraj@example.com",
      }}
    />
  );
}
```

Declared props:
- `avatar` (string); default: undefined — URL of user avatar image
- `avatarAlt` (string); default: undefined — Alt text for the avatar image
- `name` (string); default: 'Suraj Maurya' — Display name in expanded and profile views
- `role` (string); default: 'Frontend Developer' — Subtitle or profession title
- `description` (string); default: 'Building thoughtful interfaces...' — Bio or description text rendered in profile view
- `greeting` (string); default: 'Hello, I am [name]' — Custom message displayed in expanded state
- `statusText` (string); default: 'Available for work' — Optional availability chip displayed beside name
- `metadata` (DynamicIslandMetadataItem[]); default: undefined — Key-value badges rendered in profile card
- `socials` (DynamicIslandSocials); default: 5 default links — Social links as an array of items or platform key-value object
- `state` ('collapsed' | 'expanded' | 'profile' | 'share'); default: undefined — Controlled state value
- `defaultState` ('collapsed' | 'expanded' | 'profile' | 'share'); default: 'collapsed' — Initial uncontrolled state
- `onStateChange` ((state: DynamicIslandState) => void); default: undefined — Callback invoked whenever state changes
- `profileContent` (ReactNode); default: undefined — Custom ReactNode replacing default profile body
- `shareContent` (ReactNode); default: undefined — Custom ReactNode replacing default share dock
- `className` (string); default: undefined — Optional additional styling applied to the island container
