## Usage

Import path and example from component metadata:

```tsx
import { ExpandableDataRow } from "@/components/ui/expandable-data-row";

export function Demo() {
  return (
    <ExpandableDataRow
      items={[
        {
          id: "usr_01",
          user: { name: "Sarah Connor", email: "sarah@cyberdyne.io" },
          status: "active",
          revenue: "$4,280",
          date: "Oct 24, 2026",
          metadata: { plan: "Enterprise Plus", sessions: 482 },
        }
      ]}
    />
  );
}
```

Declared props:
- `items` (DataRowItem[]); default: [...] — Data records with user, status, revenue, and metadata
- `allowMultiple` (boolean); default: false — Permit multiple expanded rows concurrently
- `defaultExpandedIds` (string[]); default: ['usr_01'] — Initially expanded row identifiers
- `isLoading` (boolean); default: false — Displays pulse skeleton loaders during data fetch
- `onRowAction` ((action: string, row: DataRowItem) => void); default: undefined — Callback fired on row action buttons
