## Usage

Import path and example from component metadata:

```tsx
import { FAQ } from "@/components/ui/faq";

export function Demo() {
  return (
    <FAQ
      allowMultiple
      searchable
      items={[
        {
          id: "1",
          question: "What makes EasyUI different?",
          answer: "EasyUI is distributed directly into your codebase via the official shadcn CLI, powered by spring physics rather than rigid ease-in-out transitions."
        },
        {
          id: "2",
          question: "Can I customize the styling?",
          answer: "Yes! All components are built with standard Tailwind CSS utility classes and clean React TypeScript code with zero proprietary wrappers."
        }
      ]}
    />
  );
}
```

Declared props:
- `items` (FAQItem[]); default: [] — Array of FAQ items with id, question, answer, category, badge, icon
- `allowMultiple` (boolean); default: false — Allows multiple accordion items to remain open simultaneously
- `defaultOpen` (string[] | string); default: undefined — Default expanded item ID(s) on initial mount
- `openIds` (string[]); default: undefined — Controlled list of currently expanded item IDs
- `onOpenChange` ((ids: string[]) => void); default: undefined — Callback fired when open item selection changes
- `iconStyle` ('chevron' | 'plus-minus' | 'custom'); default: 'chevron' — Indicator icon style
- `searchable` (boolean); default: false — Displays search filter bar above FAQ items
- `showCategories` (boolean); default: false — Displays category filter pills above items
- `variant` ('unified' | 'separated'); default: 'unified' — Visual presentation layout
