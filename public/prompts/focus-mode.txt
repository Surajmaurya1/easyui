Install and integrate the EasyUI Focus Mode component into my project.

## Usage

Import path and example from component metadata:

```tsx
import { FocusMode } from "@/components/ui/focus-mode";

export function Demo() {
  return (
    <FocusMode
      items={[
        {
          id: "mrr",
          title: "Monthly Recurring Revenue",
          metric: "$148,290",
          delta: "+18.4%",
          content: <p>Enterprise plan renewals</p>
        }
      ]}
    />
  );
}
```

Declared props:
- `items` (FocusModeItem[]); default: [...] — List of dashboard cards or sections
- `focusedId` (string | null); default: null — Controlled focused card ID
- `onFocusChange` ((id: string | null) => void); default: undefined — Callback fired when focused element changes
- `dimOpacity` (number); default: 0.2 — Opacity applied to unfocused background cards
