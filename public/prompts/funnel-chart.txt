Install and integrate the EasyUI Funnel Chart component into my project.

## Usage

Import path and example from component metadata:

```tsx
import { FunnelChart } from "@/components/ui/funnel-chart";

const stages = [
  { label: "Visited site", value: 48200 },
  { label: "Signed up", value: 15840 },
  { label: "Created project", value: 9120 },
  { label: "Started paid plan", value: 1380 },
];

export function Demo() {
  return (
    <div className="w-full max-w-lg rounded-2xl bg-white p-5 dark:bg-neutral-950">
      <FunnelChart stages={stages} />
    </div>
  );
}
```

Declared props:
- `stages` (FunnelStage[]) — Ordered stages with a label, value, and optional color
- `formatValue` ((n: number) => string); default: Intl.NumberFormat — Formats stage values in the chart, tooltip, and data table
- `showSummary` (boolean); default: true — Shows overall conversion and the biggest drop-off above the funnel
- `animated` (boolean); default: true — Enables bridge, bar, and chip entrance animations
- `ariaLabel` (string); default: auto-generated — Accessible chart description and data table caption
- `className` (string); default: "" — Additional CSS classes for the funnel wrapper
