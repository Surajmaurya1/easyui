## Usage

Import path and example from component metadata:

```tsx
import { GlitchText } from "@/components/ui/glitch-text";

export function Demo() {
  return (
    <div className="flex flex-col items-center gap-6 p-8">
      {/* 1. RGB Split (Chromatic Aberration) */}
      <GlitchText
        as="h2"
        text="CHROMATIC SPLIT"
        variant="rgb-split"
        color1="#00f0ff"
        color2="#ff0055"
        className="text-4xl font-black tracking-tight"
      />

      {/* 2. Cyberpunk Slicing */}
      <GlitchText
        as="h2"
        text="CYBERPUNK SLICE"
        variant="slice"
        color1="#22c55e"
        color2="#a855f7"
        className="text-4xl font-black tracking-tight"
      />

      {/* 3. Matrix Scramble Decode on Hover */}
      <GlitchText
        as="span"
        text="SYSTEM BREACH DETECTED"
        variant="scramble"
        trigger="hover"
        color1="#10b981"
        className="text-lg font-mono text-emerald-400 cursor-pointer"
      />
    </div>
  );
}
```

Declared props:
- `text` (string) — The text string to animate with the cybernetic glitch effects
- `variant` ('rgb-split' | 'slice' | 'vhs' | 'scramble' | 'pulse'); default: 'rgb-split' — Visual animation mode: chromatic aberration, horizontal slicing, VHS jitter, matrix decode, or voltage pulse
- `trigger` ('continuous' | 'hover' | 'click'); default: 'continuous' — Interaction trigger mode governing when the glitch animation activates
- `color1` (string); default: '#00e571' — Primary chromatic aberration color (alias: greenColor)
- `color2` (string); default: '#8b00ff' — Secondary chromatic aberration color (alias: purpleColor)
- `intensity` ('low' | 'medium' | 'high'); default: 'medium' — Glitch magnitude scaling multiplier for displacement, skew, and jitter
- `duration` (number); default: 0.5 — Duration in seconds of an active glitch burst cycle
- `repeatDelay` (number); default: 2.5 — Rest interval in seconds between continuous glitch bursts
- `as` (keyof JSX.IntrinsicElements); default: 'span' — HTML tag to render as (e.g. 'h1', 'h2', 'span', 'p', 'div')
- `className` (string) — Additional CSS classes for font size, weight, color, and positioning
