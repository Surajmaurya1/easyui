## Usage

Import path and example from component metadata:

```tsx
<GlyphMatrix
  className="h-[500px] w-full rounded-2xl"
  color="#00FF66"
  headColor="#FFFFFF"
  speed={1.2}
  interactive
>
  <div className="text-center">
    <h2 className="text-3xl font-bold text-white tracking-tight">Wake up, Neo...</h2>
    <p className="text-emerald-400/80 text-sm mt-2 font-mono">The Matrix has you.</p>
  </div>
</GlyphMatrix>
```

Declared props:
- `fontSize` (number); default: 16 — Font size in pixels for the glyph grid
- `color` (string); default: '#00FF66' — Primary rain stream color
- `headColor` (string); default: '#FFFFFF' — Color of the leading head glyph in each column
- `backgroundColor` (string); default: '#050505' — Background color used for trail fading
- `speed` (number); default: 1 — Fall speed multiplier
- `fadeRate` (number); default: 0.06 — Decay rate per frame for phosphor trails
- `interactive` (boolean); default: true — Whether mouse proximity disturbs and accelerates glyph streams
- `paused` (boolean); default: false — Pauses stream animation
- `fullPage` (boolean); default: false — Fixes canvas to fill the entire viewport as a full-page background
- `opacity` (number); default: 1 — Overall opacity of the matrix backdrop
- `children` (React.ReactNode) — Optional content layered over the matrix background
