## Usage

Import path and example from component metadata:

```tsx
import { useState } from "react";
import { HamburgerMenu } from "@/components/ui/hamburger-menu";

export function Demo() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <HamburgerMenu
      isOpen={isOpen}
      onChange={setIsOpen}
      size={24}
    />
  );
}
```

Declared props:
- `isOpen` (boolean) — Active open/closed toggle state
- `onChange` ((isOpen: boolean) => void) — Callback fired on user interaction
- `size` (number); default: 24 — Width and height of the icon bounding box in pixels
- `color` (string); default: 'currentColor' — Color of the SVG/CSS line strokes
- `label` (string); default: 'Menu' — Accessible name announced to assistive tech
- `disabled` (boolean); default: false — Disables button interactions
