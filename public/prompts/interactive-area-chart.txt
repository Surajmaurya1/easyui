## Usage

Import path and example from component metadata:

```tsx
import { InteractiveAreaChart } from "@/components/ui/interactive-area-chart";

export function Demo() {
  return (
    <div className="w-full max-w-2xl p-6 bg-white dark:bg-neutral-950 rounded-2xl border border-neutral-200 dark:border-neutral-800">
      <InteractiveAreaChart title="Monthly Recurring Revenue" />
    </div>
  );
}
```

Declared props:
- `data` (AreaChartData); default: DEFAULT_AREA_CHART_DATA — Dictionary of time-series datasets keyed by range labels (e.g. 7D, 30D, 1Y)
- `defaultRange` (string); default: "30D" — Initial active range key
- `title` (string); default: "Revenue" — Chart title displayed in header
- `height` (number); default: 280 — Fixed pixel height of the chart SVG area
- `className` (string); default: "" — Additional CSS class names
