## Usage

Import path and example from component metadata:

```tsx
import { InteractiveTimeline } from "@/components/ui/interactive-timeline";

const deploymentSteps = [
  {
    id: "step-1",
    title: "Build & Artifact Verification",
    timestamp: "10:42 AM · 48s",
    status: "completed" as const,
    tag: "CI/CD",
    commitHash: "9f8a12bc",
    metrics: [{ label: "Bundle Size", value: "142 KB" }, { label: "Tree Shake", value: "99.4%" }],
  },
  {
    id: "step-2",
    title: "Global Edge Replication",
    timestamp: "10:43 AM · Active",
    status: "in-progress" as const,
    tag: "Infra",
    description: "Replicating immutable build layers across 32 regional edge locations.",
  },
  {
    id: "step-3",
    title: "Traffic Cutover & Smoke Test",
    timestamp: "Pending",
    status: "pending" as const,
    tag: "DNS",
  },
];

export function Demo() {
  return <InteractiveTimeline items={deploymentSteps} />;
}
```

Declared props:
- `items` (TimelineItem[]); default: [] — Array of timeline step items
- `defaultSelectedId` (string); default: items[0]?.id — ID of the item initially expanded
- `collapsible` (boolean); default: true — Whether cards can be expanded/collapsed on click
- `onItemSelect` ((item: TimelineItem) => void); default: undefined — Callback invoked when a timeline node or card is selected
- `className` (string); default: undefined — Optional CSS classes for outer container
