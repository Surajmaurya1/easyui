## Usage

Import path and example from component metadata:

```tsx
import { useState } from "react";
import { IOSSearchBar } from "@/components/ui/ios-search-bar";

export function Demo() {
  const [query, setQuery] = useState("");

  return (
    <IOSSearchBar
      value={query}
      onChange={setQuery}
      placeholder="Search documentation..."
      onSubmit={(q) => console.log("Searching:", q)}
    />
  );
}
```

Declared props:
- `value` (string) — Current search query string
- `onChange` ((value: string) => void) — Input change handler
- `onSubmit` ((value: string) => void); default: undefined — Fired when Enter is pressed
- `onClear` (() => void); default: undefined — Callback when clear button is clicked
- `placeholder` (string); default: 'Search...' — Placeholder label
- `collapsedWidth` (number | string); default: '220px' — Width before focus
- `expandedWidth` (number | string); default: '340px' — Width after focus
