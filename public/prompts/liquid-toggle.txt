## Task

Install and integrate the EasyUI Liquid Toggle component into my project.

A toggle with a liquid/blob-like transition. The internal shape deforms organically as it travels from off to on — stretching along the travel axis and settling into a natural blob shape rather than simply translating.

Category: Buttons.

## Usage

Import path and example from component metadata:

```tsx
import { LiquidToggle } from "@/components/ui/liquid-toggle";

export function Demo() {
  const [on, setOn] = React.useState(false);
  return (
    <div className="flex items-center gap-2">
      <LiquidToggle value={on} onChange={setOn} />
      <span className="text-sm">{on ? 'Enabled' : 'Disabled'}</span>
    </div>
  );
}
```

Declared props:
- `value` (boolean); default: undefined — Controlled value
- `defaultValue` (boolean); default: false — Initial value for uncontrolled mode
- `onChange` ((value: boolean) => void); default: undefined — Toggle change callback
- `disabled` (boolean); default: false — Disabled state
- `offLabel` (string); default: 'Off' — Screen reader label when off
- `onLabel` (string); default: 'On' — Screen reader label when on
- `accentColor` (string); default: '#FAFAFA' — Blob color when on
- `showLabels` (boolean); default: true — Show OFF/ON text inside the track
- `width` (number); default: 56 — Track width in px
- `height` (number); default: 32 — Track height in px
