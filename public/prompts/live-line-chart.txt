## Usage

Import path and example from component metadata:

```tsx
import { LiveLineChart } from "@/components/ui/live-line-chart";

export function Demo() {
  return (
    <div className="w-full max-w-2xl rounded-2xl bg-white p-5 dark:bg-neutral-950">
      <LiveLineChart
        initial={[1240, 1280, 1235, 1310, 1290]}
        unit="req/s"
        height={220}
        source={(push) => {
          const id = setInterval(() => push(1200 + Math.random() * 300), 1000);
          return () => clearInterval(id);
        }}
      />
    </div>
  );
}
```

Declared props:
- `source` ((push) => void | (() => void)) — Data feed subscription; call push(value) for each new reading and return a cleanup
- `initial` (number[]) — Known values, oldest to newest, spaced intervalMs apart and ending now
- `intervalMs` (number); default: 1000 — Approximate arrival interval and the smoothing delay
- `windowSeconds` (number); default: 60 — Seconds visible in the scrolling window
- `height` (number); default: 220 — Chart height in pixels
- `color` (string); default: CHART_COLORS[0] — Line stroke and area gradient color
- `unit` (string); default: "" — Unit shown beside the readout and tooltip values
- `formatValue` ((n: number) => string); default: Intl.NumberFormat — Formats the current value, tooltip, and aria text
- `domain` ([number, number]) — Fixed y-range instead of auto-scaling to the visible window
- `showReadout` (boolean); default: true — Shows the large current value, delta, and pause button
- `ariaLabel` (string); default: auto-generated — Accessible description for the chart image role
- `className` (string); default: "" — Additional CSS classes for the chart wrapper
