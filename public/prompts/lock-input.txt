## Task

Install and integrate the EasyUI LockInput component into my project.

A text input whose focus state subtly "locks" into place — a focus ring scales in from the center and the border tweens to active, giving the impression that the input snaps closed on itself.

## Usage

Import path and example from component metadata:

```tsx
import { LockInput } from "@/components/ui/lock-input";
import { Mail } from "lucide-react";

export function Demo() {
  return (
    <div className="space-y-4 max-w-sm">
      <LockInput
        label="Email"
        type="email"
        placeholder="you@studio.dev"
        leftIcon={<Mail className="w-3.5 h-3.5" />}
        description="We'll send a confirmation link here."
      />
      <LockInput
        label="Workspace"
        placeholder="acme"
        error="That workspace is already taken."
      />
    </div>
  );
}
```

Declared props:
- `label` (string); default: undefined — Visible label rendered above the input
- `description` (string); default: undefined — Helper text below the input
- `error` (string); default: undefined — Error message; presence triggers danger styling
- `leftIcon` (React.ReactNode); default: undefined — Icon element placed before the input value
- `rightIcon` (React.ReactNode); default: undefined — Icon element placed after the input value
- `disabled` (boolean); default: false — Prevents interaction and applies 30% disabled opacity
