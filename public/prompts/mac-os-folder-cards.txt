## Usage

Import path and example from component metadata:

```tsx
import { MacOSFolderCards } from "@/components/ui/macos-folder-cards";

export function Demo() {
  return (
    <MacOSFolderCards
      folderTitle="Components"
      folderCategory="Pipeline"
      items={[
        { id: '1', title: 'Registry Sync', description: 'Catalog reacts to source changes.', meta: '01' },
        { id: '2', title: 'SEO Audit', description: 'Metadata verified before release.', meta: '02' },
      ]}
    />
  );
}
```

Declared props:
- `folderTitle` (string); default: 'Components' — Title label of the folder icon
- `folderCategory` (string); default: 'Pipeline' — Category breadcrumb for expanded header
- `items` (MacOSFolderCardItem[]); default: demo items — Cards rendered in the expanded grid
- `defaultOpen` (boolean); default: false — Initial open/expanded state
