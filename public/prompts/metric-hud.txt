## Usage

Import path and example from component metadata:

```tsx
import { MetricHUD } from "@/components/ui/metric-hud";

const metrics = [
  {
    id: "latency",
    label: "p99 Latency",
    value: "14.2",
    unit: "ms",
    delta: { value: "-18.4%", trend: "down" as const, isPositiveGood: true },
    status: "normal" as const,
    timeSeries: {
      "1h": [18, 17, 16, 15, 14, 14.2],
      "24h": [24, 21, 19, 18, 16, 14.2],
      "7d": [32, 28, 22, 19, 15, 14.2],
    },
  },
  {
    id: "throughput",
    label: "API Throughput",
    value: "84.5k",
    unit: "req/s",
    delta: { value: "+12.1%", trend: "up" as const, isPositiveGood: true },
    status: "normal" as const,
    timeSeries: {
      "1h": [60, 65, 72, 78, 81, 84.5],
      "24h": [40, 52, 68, 74, 80, 84.5],
      "7d": [30, 45, 60, 70, 80, 84.5],
    },
  },
];

export function Demo() {
  return <MetricHUD metrics={metrics} defaultTimeRange="24h" />;
}
```

Declared props:
- `metrics` (MetricItem[]); default: [] — Array of telemetry metric definitions with time-series data
- `timeRanges` (string[]); default: ['1h', '24h', '7d', '30d'] — Available time window filters
- `defaultTimeRange` (string); default: '24h' — Initial active time range
- `className` (string); default: undefined — Custom CSS container styling
