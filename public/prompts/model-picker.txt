## Usage

Import path and example from component metadata:

```tsx
import { ModelPicker, type AIModel } from "@/components/ui/ModelPicker";

const models: AIModel[] = [
  { id: "claude", name: "Claude", speed: 3, intelligence: 5 },
  { id: "claude-haiku", name: "Claude Haiku", speed: 5, intelligence: 2 },
  { id: "gemini-pro", name: "Gemini Pro", speed: 4, intelligence: 5 },
  { id: "gemini-flash", name: "Gemini Flash", speed: 5, intelligence: 3 },
  { id: "gpt", name: "GPT", speed: 3, intelligence: 5 },
  { id: "gpt-mini", name: "GPT Mini", speed: 5, intelligence: 2 },
];

export function Demo() {
  return <ModelPicker models={models} defaultValue="gpt" />;
}
```

Declared props:
- `models` (AIModel[]) — Models to display, optionally grouped by provider.
- `value` (string) — Selected model ID for controlled usage.
- `defaultValue` (string) — Initial model ID for uncontrolled usage.
- `onChange` ((id: string, model: AIModel) => void) — Called when a model is selected.
- `variant` ("pill" | "field"); default: "pill" — Compact composer chip or full-width labeled field.
- `searchable` (boolean | "auto"); default: "auto" — Whether to show search; auto enables it for more than six models.
- `footer` (ReactNode) — Optional content displayed beneath the model list.
- `disabled` (boolean); default: false — Disables opening the picker.
