## Task

Install and integrate the EasyUI Morphing Blob component into my project.

An ambient, accessible SVG blob background that continuously morphs with spring physics and subtly follows the cursor for a fluid, interactive visual effect.

## Usage

Import path and example from component metadata:

```tsx
import { MorphingBlob } from "@/components/ui/morphing-blob";

export function Demo() {
  return (
    <div className="relative h-96 w-full overflow-hidden rounded-2xl bg-[#0E0E0E]">
      <MorphingBlob
        width={600}
        height={400}
        cursorFollow
        cursorStrength={0.35}
        cursorSmoothness={0.08}
        colors={['#7C3AED', '#06B6D4']}
        className="absolute -top-20 -left-20 opacity-70"
      />

      <div className="relative z-10 p-8 text-white">
        Content sits above the blob.
      </div>
    </div>
  );
}
```

Declared props:
- `width` (number); default: 400 — Width of the SVG viewport in pixels
- `height` (number); default: 400 — Height of the SVG viewport in pixels
- `points` (number); default: 8 — Number of anchor points used to construct the blob shape
- `baseRadius` (number); default: 120 — Resting radius of the blob in pixels
- `variance` (number); default: 28 — Maximum radius variation applied to each anchor point during morphing
- `speed` (number); default: 0.7 — Controls how frequently new random morph targets are generated
- `stiffness` (number); default: 45 — Spring stiffness controlling how strongly anchor points move toward their targets
- `damping` (number); default: 9 — Spring damping controlling the resistance and smoothness of the blob motion
- `cursorFollow` (boolean); default: true — Enables or disables cursor-follow interaction
- `cursorStrength` (number); default: 0.35 — Controls how strongly the blob moves toward the cursor position
- `cursorSmoothness` (number); default: 0.08 — Controls how smoothly the blob catches up to the cursor; lower values create more fluid trailing motion
- `colors` ([string, string]); default: ['#7C3AED', '#06B6D4'] — Two colors used for the blob gradient, from start to end
- `className` (string); default: undefined — Additional CSS classes for positioning, sizing, opacity, layering, and other styling
