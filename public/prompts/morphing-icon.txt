## Usage

Import path and example from component metadata:

```tsx
<button
  onClick={() => setIsBookmarked((prev) => !prev)}
  className="p-2 rounded-xl bg-surface-raised border border-border hover:bg-surface-hover transition-colors"
  aria-label={isBookmarked ? "Remove bookmark" : "Save bookmark"}
>
  <MorphingIcon
    active={isBookmarked}
    from={<Bookmark className="w-5 h-5 text-text-secondary" />}
    to={<BookmarkCheck className="w-5 h-5 text-emerald-400" />}
    size={20}
  />
</button>
```

Declared props:
- `from` (React.ReactNode); default: undefined — Default icon element shown when inactive
- `to` (React.ReactNode); default: undefined — Target icon element shown when active
- `active` (boolean); default: false — Whether the target icon state is currently active
- `duration` (number); default: 0.3 — Duration of the morph transition in seconds
- `size` (number); default: 20 — Width and height of the icon container in pixels
- `className` (string); default: undefined — Optional CSS class for styling the container
