## Usage

Import path and example from component metadata:

```tsx
import { MorphingShapeLoader } from "@/components/ui/morphing-shape-loader";

export function Demo() {
  return (
    <MorphingShapeLoader
      shapes={['circle', 'square', 'triangle', 'hexagon', 'star']}
      duration={1.4}
      holdDuration={0.3}
    />
  );
}
```

Declared props:
- `shapes` (ShapeKind[]); default: ['circle','square','triangle','circle'] — Ordered list of shapes to cycle through
- `duration` (number); default: 1.6 — Morph duration per shape change in seconds
- `holdDuration` (number); default: 0.4 — Hold duration at each shape in seconds
- `loop` (boolean); default: true — Loop the shape sequence
- `size` (number); default: 96 — Loader size in pixels (square)
- `color` (string); default: '#FAFAFA' — Stroke or fill color
- `filled` (boolean); default: false — Filled variant instead of stroke
