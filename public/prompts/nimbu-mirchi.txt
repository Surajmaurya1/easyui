## Usage

Import path and example from component metadata:

```tsx
import { NimbuMirchi } from "@/components/ui/nimbu-mirchi";

export function Demo() {
  return (
    <div className="w-full max-w-md mx-auto rounded-2xl border border-[#1F1F1F] overflow-hidden">
      <NimbuMirchi
        maxRotation={13}
        stiffnessX={55}
        stiffnessY={45}
        damping={9}
        caption="Hanging nimbu-mirchi charm"
      />
    </div>
  );
}
```

Declared props:
- `maxRotation` (number); default: 13 — Maximum rotation in degrees at full pointer offset
- `stiffnessX` (number); default: 55 — Pointer X spring stiffness (higher = snappier follow)
- `stiffnessY` (number); default: 45 — Pointer Y spring stiffness
- `damping` (number); default: 9 — Spring damping (higher = less swing overshoot)
- `caption` (string); default: undefined — Optional screen-reader caption for the charm
- `className` (string); default: undefined — Additional Tailwind classes merged into the container
