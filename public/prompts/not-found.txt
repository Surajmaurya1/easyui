## Usage

Import path and example from component metadata:

```tsx
import { NotFound } from "@/components/ui/not-found";

export default function NotFoundPage() {
  return (
    <div className="min-h-screen flex items-center justify-center p-6 bg-[#111113]">
      <NotFound
        title="This page took a wrong turn."
        description="The requested page doesn't exist or may have moved."
        actionLabel="Go back home"
        onAction={() => window.location.href = "/"}
      />
    </div>
  );
}
```

Declared props:
- `errorCode` (string); default: '404' — Main error code glyphs rendered as physical interactive objects
- `badgeLabel` (string); default: undefined — Optional status tag displayed above the glyphs
- `title` (string); default: 'This page took a wrong turn.' — Primary heading title
- `description` (string); default: 'The requested page doesn\'t exist or may have moved.' — Descriptive secondary body copy
- `actionLabel` (string); default: 'Go back home' — Label for the primary recovery action button
- `onAction` (() => void); default: undefined — Callback when primary action button is clicked
- `secondaryActionLabel` (string); default: undefined — Optional label for the secondary action button
- `onSecondaryAction` (() => void); default: undefined — Callback when secondary action button is clicked
- `className` (string); default: undefined — Optional custom container CSS classes
