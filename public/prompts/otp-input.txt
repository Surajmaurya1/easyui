## Usage

Import path and example from component metadata:

```tsx
import { OTPInput } from "@/components/ui/otp-input";

export function Demo() {
  return (
    <OTPInput
      length={6}
      autoFocus
      onComplete={(code) => console.log("Submitted code:", code)}
    />
  );
}
```

Declared props:
- `length` (number); default: 6 — Number of digit boxes to render
- `value` (string); default: undefined — Controlled value; omit to let the component manage its own state
- `onChange` ((value: string) => void); default: undefined — Called with the joined code whenever any digit changes
- `onComplete` ((value: string) => void); default: undefined — Called once with the full code when every box is filled
- `autoFocus` (boolean); default: false — Focuses the first box on mount
- `disabled` (boolean); default: false — Disables all digit boxes
- `className` (string); default: undefined — Classes applied to the wrapping group element
- `boxClassName` (string); default: undefined — Classes applied to each individual digit box
