## Usage

Import path and example from component metadata:

```tsx
import { PaymentStatus } from "@/components/ui/payment-status";

export function Demo() {
  return (
    <PaymentStatus
      status="success"
      amount="$149.00"
      transactionId="tx_8830192a"
      paymentMethod="Apple Pay"
      last4="4242"
    />
  );
}
```

Declared props:
- `status` ('processing' | 'verifying' | 'success' | 'failed' | 'refunded'); default: 'processing' — Current lifecycle state of payment
- `amount` (string | number); default: '$149.00' — Transaction total amount formatted or numeric
- `currency` (string); default: '$' — Currency symbol prepended to amount
- `transactionId` (string); default: 'tx_9842a8d11c7f' — Unique transaction identifier
- `date` (string | Date); default: 'Today at 3:42 PM' — Date/time timestamp of payment
- `paymentMethod` (string); default: 'Apple Pay' — Payment gateway or card provider
- `last4` (string); default: '4242' — Last 4 digits of card or account
- `items` (PaymentReceiptItem[]); default: [...] — Itemized purchase items for detailed receipt view
- `merchantName` (string); default: 'EasyUI Cloud' — Merchant or brand organization name
- `onRetry` (() => void); default: undefined — Callback fired when user clicks Try Again
- `onChangePaymentMethod` (() => void); default: undefined — Callback fired when user changes card method
