## Usage

Import path and example from component metadata:

```tsx
import { PeekCard } from "@/components/ui/peek-card";

export function Demo() {
  return (
    <PeekCard
      data={{
        title: "Payment #3948",
        amount: "$249.00",
        customer: { name: "Alexander Wright", email: "alex@acme.com" },
        status: "Succeeded",
      }}
    >
      <span className="underline decoration-dotted cursor-pointer">
        Payment #3948
      </span>
    </PeekCard>
  );
}
```

Declared props:
- `children` (ReactNode); default: undefined — Trigger target element wrapped by peek card
- `data` (PeekCardData); default: [...] — Structured preview dataset
- `delay` (number); default: 200 — Hover activation delay in milliseconds
- `placement` ('top' | 'bottom' | 'auto'); default: 'auto' — Preferred emergence direction
- `isLoading` (boolean); default: false — Renders skeleton placeholder during async lookup
