## Usage

Import path and example from component metadata:

```tsx
import { PhotoBox } from "@/components/ui/photo-box";

export function Demo() {
  return (
    <div className="w-full py-12 flex justify-center">
      <PhotoBox />
    </div>
  );
}
```

Declared props:
- `prints` (PhotoPrint[]); default: DEFAULT_PRINTS — Up to 3 photo prints to display inside the box slots (title, caption, src or art)
- `title` (string); default: '写真箱' — Headline kanji or text displayed on the frosted cover
- `subtitle` (string); default: 'Photo Box · 3 prints' — Subtext printed beneath the headline title
- `open` (boolean); default: undefined — Optional controlled open state for external hover or trigger controls
- `className` (string); default: '' — Optional CSS class overrides applied to the outer stage container
- `onOpenChange` ((open: boolean) => void); default: undefined — Callback invoked whenever the box opens or closes
- `onSelect` ((id: string | null) => void); default: undefined — Callback invoked when an individual polaroid print is inspected or closed
