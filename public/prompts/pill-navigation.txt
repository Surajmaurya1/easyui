## Usage

Import path and example from component metadata:

```tsx
import { PillNavigation } from "@/components/ui/pill-navigation";

export function Demo() {
  return (
    <PillNavigation
      items={[
        { id: 'overview', label: 'Overview' },
        {
          id: 'motion',
          label: 'Motion',
          children: [
            { id: 'springs', label: 'Spring Physics' },
            { id: 'caustics', label: 'Liquid Caustics' },
          ],
        },
        { id: 'code', label: 'Code' },
      ]}
      onChange={(mainId, subId) => console.log(mainId, subId)}
    />
  );
}
```

Declared props:
- `items` (PillNavigationItem[]); default: demo items — Navigation items with optional submenu children
- `defaultValue` (string); default: first item id — Initial selected item id
- `defaultSubValue` (string); default: undefined — Initial selected submenu item id
- `onChange` ((id: string, subId?: string) => void); default: undefined — Selection callback
