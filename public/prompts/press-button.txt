## Usage

Import path and example from component metadata:

```tsx
import { PressButton } from "@/components/ui/press-button";

export function Demo() {
  return (
    <div className="flex flex-wrap items-center gap-3">
      <PressButton variant="primary">Save changes</PressButton>
      <PressButton variant="secondary" pressStrength={0.05}>Cancel</PressButton>
      <PressButton variant="outline">Learn more</PressButton>
      <PressButton variant="ghost">Skip</PressButton>
    </div>
  );
}
```

Declared props:
- `variant` ('primary' | 'secondary' | 'outline' | 'ghost'); default: 'primary' — Visual presentation style
- `size` ('sm' | 'md' | 'lg' | 'icon'); default: 'md' — Dimensions and typography scale
- `pressStrength` (number); default: 0.04 — Compression amount on press (0-1, clamped 0.01-0.06)
- `fullWidth` (boolean); default: false — Stretches button to 100% width of parent container
- `disabled` (boolean); default: false — Prevents interaction and applies 30% disabled opacity
