## Usage

Import path and example from component metadata:

```tsx
import { Pricing } from "@/components/ui/pricing";

export function Demo() {
  // Renders the EasyUI default Free + Pro pair out of the box.
  return <Pricing />;
}
```

Declared props:
- `freeTier` (PricingTier); default: EasyUI defaults — Configuration object for the Free tier — { name, tagline, price, cadence, features, ctaLabel, onCtaClick }. Optional: the component ships with sensible EasyUI defaults.
- `proTier` (PricingTier); default: EasyUI defaults — Configuration object for the Pro tier — same shape as freeTier. Optional: defaults to the EasyUI Pro tier ($29, one-time payment).
- `reverse` (boolean); default: false — Swaps the order so Pro is rendered on the left
- `eyebrow` (string); default: undefined — Optional uppercase label rendered above the heading
- `heading` (string); default: undefined — Optional headline rendered above the cards
- `subheading` (string); default: undefined — Optional supporting copy rendered beneath the heading
- `className` (string); default: undefined — Optional Tailwind classes appended to the outer section
