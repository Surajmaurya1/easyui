## Usage

Import path and example from component metadata:

```tsx
import { ProfileCard } from "@/components/ui/profile-card";

export function Demo() {
  return (
    <div className="w-full max-w-md mx-auto">
      <ProfileCard
        name="Suraj"
        username="@surajmaurya_m"
        description="Building EasyUI. Engineer."
        followers="200K"
        posts="72"
        website="easyui.site"
        onAction={() => console.log('Follow clicked')}
      />
    </div>
  );
}
```

Declared props:
- `name` (string); default: 'Suraj' — Display name shown in the detail panel header
- `username` (string); default: '@surajmaurya_m' — Handle rendered as the small caption under the name
- `description` (string); default: 'Building EasyUI. Engineer.' — Biographical text shown under the name
- `followers` (string); default: '200K' — Pre-formatted follower count
- `posts` (string); default: '72' — Pre-formatted post count
- `website` (string); default: 'easyui.site' — Website domain — link href is auto-prefixed with https://
- `actionLabel` (string); default: 'Follow' — Label for the primary action button
- `onAction` (() => void); default: undefined — Click handler for the primary action button
- `className` (string); default: undefined — Additional Tailwind classes merged into the card root
