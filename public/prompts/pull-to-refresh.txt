## Usage

Import path and example from component metadata:

```tsx
import { PullToRefresh, FinancialStatsCard } from "@/components/ui/pull-to-refresh";

export function Demo() {
  return (
    <PullToRefresh
      onRefresh={async () => {
        await new Promise((res) => setTimeout(res, 1200));
      }}
    >
      <FinancialStatsCard showMetrics showActions />
    </PullToRefresh>
  );
}
```

Declared props:
- `onRefresh` (() => Promise<void> | void); default: undefined — Async or sync callback executed when released beyond threshold
- `threshold` (number); default: 68 — Downward travel distance in pixels required to trigger refresh
- `maxPull` (number); default: 110 — Maximum drag distance limit
- `resistance` (number); default: 0.45 — Elastic resistance multiplier
- `refreshingHoldOffset` (number); default: 48 — Vertical offset to hold content at while refresh resolves
- `disabled` (boolean); default: false — Disables gesture interaction
- `showDefaultIndicator` (boolean); default: true — Show the built-in minimal circular progress indicator
- `children` (React.ReactNode); default: <FinancialStatsCard /> — Custom child content to be pulled
