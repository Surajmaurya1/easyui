## Usage

Import path and example from component metadata:

```tsx
import { RainbowButton } from "@/components/ui/rainbow-button";

export function RainbowButtonDemo() {
  return (
    <div className="flex flex-wrap items-center gap-4 p-8">
      <RainbowButton>
        Get Unlimited Access
      </RainbowButton>

      <RainbowButton variant="outline" size="sm">
        Explore Features
      </RainbowButton>
    </div>
  );
}
```

Declared props:
- `variant` ('default' | 'outline'); default: 'default' — Visual presentation style of the button surface
- `size` ('default' | 'sm' | 'lg' | 'icon'); default: 'default' — Button dimension scale and padding
- `asChild` (boolean); default: false — Render as child component (e.g. Next.js Link or a tag) passing through props and styles
- `glow` (boolean); default: true — Whether to show the ambient blurred rainbow glow drop-shadow beneath the button
- `speed` (number); default: 3 — Rainbow animation cycle duration in seconds
- `color1` (string); default: 'hsl(0 100% 63%)' — First chromatic gradient stop (red/pink)
- `color2` (string); default: 'hsl(270 100% 63%)' — Second chromatic gradient stop (purple)
- `color3` (string); default: 'hsl(210 100% 63%)' — Third chromatic gradient stop (blue)
- `color4` (string); default: 'hsl(195 100% 63%)' — Fourth chromatic gradient stop (cyan)
- `color5` (string); default: 'hsl(90 100% 63%)' — Fifth chromatic gradient stop (green)
- `className` (string) — Additional CSS classes
