## Usage

Import path and example from component metadata:

```tsx

export function Demo() {
  return (
    <RevealCard revealContent={<div>Expanded analytics & telemetry</div>}>
      <h4>Cloud Engine</h4>
    </RevealCard>
  );
}
```

- `maxTilt` (number); default: 12 — Max tilt angle in degrees
- `revealContent` (ReactNode); default: undefined — Content shown on hover
