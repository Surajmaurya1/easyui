## Usage

Import path and example from component metadata:

```tsx
import { RocketPartyPopper } from "@/components/ui/rocket-party-popper";

export function Demo() {
  return (
    <RocketPartyPopper
      title="Release Shipped"
      description="All registry, lint, and SEO checks passed."
      metric="v2.4.0 Live"
      onLaunch={() => console.log('Rocket Launched!')}
    />
  );
}
```

Declared props:
- `title` (string); default: 'Mission Accomplished' — Primary celebration headline
- `description` (string); default: 'All checks passed and your release is ready to deploy.' — Supporting celebration description
- `metric` (string); default: '100% Production Ready' — Metadata badge shown on milestone card
- `triggerLabel` (string); default: 'Launch celebration' — Label for the launch button
- `confettiCount` (number); default: 50 — Total confetti particles spawned on blast
- `defaultLaunched` (boolean); default: false — Initial launched/revealed state
- `onLaunch` (() => void); default: undefined — Callback fired on launch trigger
- `onReset` (() => void); default: undefined — Callback fired on reset
