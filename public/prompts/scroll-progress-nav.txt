Install and integrate the EasyUI Scroll Progress Navigation component into my project.

## Usage

Import path and example from component metadata:

```tsx
import { ScrollProgressNav } from "@/components/ui/scroll-progress-nav";

export function Demo() {
  return (
    <ScrollProgressNav
      sections={[
        { id: "overview", index: "01", label: "Overview" },
        { id: "features", index: "02", label: "Features" },
        { id: "components", index: "03", label: "Components" },
        { id: "docs", index: "04", label: "Documentation" }
      ]}
    />
  );
}
```

Declared props:
- `sections` (NavSectionItem[]); default: [...] — Navigation links with IDs, index numbers, and labels
- `scrollThreshold` (number); default: 150 — Scroll distance in px before morphing into floating pill
- `activeId` (string); default: undefined — Controlled active section ID override
- `onSectionClick` ((id: string) => void); default: undefined — Callback fired when user selects a section
- `position` ('top-center' | 'bottom-center' | 'top-right'); default: 'top-center' — Screen anchor position
