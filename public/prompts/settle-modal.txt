## Task

Install and integrate the EasyUI SettleModal component into my project.

A modal whose content has a tiny scale/settle instead of a generic fade. The panel scales 0.94 -> 1.02 -> 1.0 with a small y travel, then the inner content layers its own gentle settle on top.

Category: Overlays.

## Usage

Import path and example from component metadata:

```tsx
import { useState } from "react";
import { SettleModal } from "@/components/ui/settle-modal";
import { PressButton } from "@/components/ui/press-button";

export function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <PressButton onClick={() => setOpen(true)}>Open modal</PressButton>
      <SettleModal
        open={open}
        onClose={() => setOpen(false)}
        title="Confirm archive"
        description="Archived projects can be restored within 30 days."
        footer={
          <>
            <PressButton variant="ghost" onClick={() => setOpen(false)}>Cancel</PressButton>
            <PressButton variant="primary" onClick={() => setOpen(false)}>Archive</PressButton>
          </>
        }
      >
        <p className="text-sm text-[#A1A1A1] leading-relaxed">
          This project and its 14 components will be moved to the archive.
        </p>
      </SettleModal>
    </>
  );
}
```

Declared props:
- `open` (boolean); default: undefined — Whether the modal is open
- `onClose` (() => void); default: undefined — Called when the modal should close
- `title` (React.ReactNode); default: undefined — Optional title rendered at the top
- `description` (React.ReactNode); default: undefined — Optional secondary description below the title
- `children` (React.ReactNode); default: undefined — Main content area
- `footer` (React.ReactNode); default: undefined — Footer area, typically action buttons
- `hideCloseButton` (boolean); default: false — Hide the close (X) button
- `closeOnBackdrop` (boolean); default: true — Click on backdrop closes the modal
- `size` ('sm' | 'md' | 'lg'); default: 'md' — Maximum width preset
