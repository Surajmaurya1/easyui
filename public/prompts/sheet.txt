## Task

Install and integrate the EasyUI Sheet component into my project.

A draggable sheet / drawer that slides in from any side and can be dragged away to dismiss — swipe left/right sheets anywhere on touch, top/bottom sheets via the grab handle. Springs back if you let go early.

## Usage

Import path and example from component metadata:

```tsx
import {
  Sheet, SheetBody, SheetClose, SheetContent, SheetDescription,
  SheetFooter, SheetHeader, SheetTitle, SheetTrigger,
} from "@/components/ui/sheet";

<Sheet>
  <SheetTrigger className="h-9 rounded-lg bg-neutral-900 px-4 text-sm text-white dark:bg-white dark:text-neutral-900">
    Open
  </SheetTrigger>

  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Edit profile</SheetTitle>
      <SheetDescription>Make changes, then save.</SheetDescription>
    </SheetHeader>
    <SheetBody>{/* scrolls on its own */}</SheetBody>
    <SheetFooter>
      <SheetClose>Cancel</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

Declared props:
- `open` (boolean); default: undefined — Controlled open state (on Sheet)
- `defaultOpen` (boolean); default: false — Initial open state (uncontrolled)
- `onOpenChange` ((open: boolean) => void); default: undefined — Open state change callback
- `side` ('right' | 'left' | 'top' | 'bottom'); default: 'right' — Side the sheet slides in from (on SheetContent)
- `showClose` (boolean); default: true — Show the built-in close button
- `className` (string); default: undefined — Additional class for the panel
