## Usage

Import path and example from component metadata:

```tsx
import { SignUp } from "@/components/ui/sign-up";

export function Demo() {
  const handleSignUp = async (data: any) => {
    console.log("Registering account:", data);
  };

  return (
    <div className="py-8 flex justify-center">
      <SignUp
        onSubmit={handleSignUp}
        onSignInClick={() => alert("Redirect to sign in")}
      />
    </div>
  );
}
```

Declared props:
- `title` (string); default: 'Create an account' — Primary card title text
- `description` (string); default: 'Join EasyUI to access components and templates' — Subtitle description below the title
- `logo` (React.ReactNode); default: <SparklesIcon /> — Brand badge or logo displayed at the top
- `error` (string | null); default: null — Server-side registration error banner message
- `isLoading` (boolean); default: false — Submitting state displaying loader on submit button
- `onSubmit` ((data: SignUpFormData) => void); default: undefined — Form submission callback with name, email, password, confirmPassword, agreeToTerms
- `onSignInClick` (() => void); default: undefined — Callback for switching to login view
- `showSocialSignUp` (boolean); default: true — Toggles GitHub and Google SSO buttons
- `requireConfirmPassword` (boolean); default: true — Includes confirmation password field and checks match
- `termsText` (React.ReactNode); default: Default Terms & Privacy links — Custom agreement label text or JSX
