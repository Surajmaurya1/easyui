## Usage

Import path and example from component metadata:

```tsx
import { Skeleton, SkeletonAvatar, SkeletonText, SkeletonReveal } from "@/components/ui/skeleton";

<SkeletonReveal
  loading={isLoading}
  skeleton={
    <div className="flex gap-3">
      <SkeletonAvatar size={40} />
      <div className="flex-1 space-y-2">
        <Skeleton className="h-4 w-1/3" />
        <SkeletonText lines={2} />
      </div>
    </div>
  }
>
  <UserCard user={user} />
</SkeletonReveal>
```

Declared props:
- `className` (string); default: undefined — CSS classes to size and position the skeleton block
- `lines` (number); default: 3 — Number of lines for the SkeletonText component
- `size` (number); default: 40 — Pixel size for the circular SkeletonAvatar component
- `loading` (boolean); default: undefined — Active loading state for the SkeletonReveal wrapper
- `skeleton` (React.ReactNode); default: undefined — Placeholder element rendered while loading is true
