## Task

Install and integrate the EasyUI SlidePagination component into my project.

A pagination control where the active indicator slides between pages rather than instantly switching. The active background uses shared layoutId so the indicator visibly travels from one item to the next.

## Usage

Import path and example from component metadata:

```tsx
import { SlidePagination } from "@/components/ui/slide-pagination";

export function Demo() {
  return (
    <div className="flex items-center justify-center">
      <SlidePagination pageCount={12} defaultPage={5} siblingCount={1} />
    </div>
  );
}
```

Declared props:
- `pageCount` (number); default: undefined — Total number of pages
- `page` (number); default: undefined — Controlled current page
- `defaultPage` (number); default: 1 — Initial current page (uncontrolled)
- `siblingCount` (number); default: 1 — Visible pages around the current one
- `onChange` ((page: number) => void); default: undefined — Page change callback
- `showControls` (boolean); default: true — Show previous / next buttons
