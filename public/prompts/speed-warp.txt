## Usage

Import path and example from component metadata:

```tsx
<div className="relative h-[480px] w-full overflow-hidden rounded-2xl bg-[#050505] border border-border">
  <SpeedWarp speed={30} starCount={700} />
  <div className="relative z-10 flex h-full items-center justify-center">
    <h2 className="text-3xl font-bold tracking-tight text-white">Engage Warp Drive</h2>
  </div>
</div>
```

Declared props:
- `speed` (number); default: 25 — Velocity multiplier of stars moving toward the camera
- `starCount` (number); default: 600 — Total number of 3D stars rendered in the volume
- `className` (string); default: undefined — Optional custom CSS class name for styling
- `children` (React.ReactNode) — Optional overlay content rendered above the starfield
