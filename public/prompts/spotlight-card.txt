## Usage

Import path and example from component metadata:

```tsx
import { SpotlightCard } from "@/components/ui/spotlight-card";

export function Demo() {
  return (
    <SpotlightCard className="max-w-sm">
      <h3 className="text-base font-semibold text-white">Edge Computing</h3>
      <p className="text-sm text-neutral-400 mt-2">
        Deploy globally distributed stateful workloads in 35 regions.
      </p>
    </SpotlightCard>
  );
}
```

Declared props:
- `spotlightColor` (string); default: 'rgba(56, 189, 248, 0.08)' — Inner ambient radial color
- `spotlightSize` (number); default: 350 — Radius of spotlight effect in pixels
