## Usage

Import path and example from component metadata:

```tsx
import { SpotlightSearch } from "@/components/ui/spotlight-search";

export function Demo() {
  const [open, setOpen] = useState(false);

  return (
    <div>
      <button onClick={() => setOpen(true)}>Press ⌘K to search</button>
      <SpotlightSearch open={open} onOpenChange={setOpen} />
    </div>
  );
}
```

Declared props:
- `open` (boolean); default: false — Controlled visibility state
- `onOpenChange` ((open: boolean) => void); default: undefined — Callback fired when modal visibility toggles
- `items` (SpotlightSearchItem[]); default: [...] — List of searchable actions and components
- `placeholder` (string); default: 'Search components, actions...' — Input placeholder text
- `onSelect` ((item: SpotlightSearchItem) => void); default: undefined — Callback fired when item is chosen
