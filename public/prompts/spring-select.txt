## Usage

Import path and example from component metadata:

```tsx
import { SpringSelect } from "@/components/ui/spring-select";

export function Demo() {
  return (
    <div className="max-w-sm">
      <SpringSelect
        label="Workspace"
        placeholder="Choose a workspace"
        defaultValue="design"
        options={[
          { value: "design", label: "Design Team", description: "12 members" },
          { value: "eng", label: "Engineering", description: "34 members" },
          { value: "ops", label: "Operations", description: "8 members" },
          { value: "labs", label: "R&D Labs", description: "5 members", disabled: true },
        ]}
      />
    </div>
  );
}
```

Declared props:
- `options` (SpringSelectOption[]); default: [] — Array of options with value, label, optional description, and disabled
- `value` (string); default: undefined — Controlled value
- `defaultValue` (string); default: undefined — Initial value (uncontrolled)
- `placeholder` (string); default: 'Select…' — Placeholder text when no value is selected
- `onChange` ((value: string) => void); default: undefined — Called when a new value is selected
- `label` (string); default: undefined — Visible label rendered above the trigger
- `disabled` (boolean); default: false — Prevents interaction
- `error` (string); default: undefined — Error message; presence triggers danger styling
