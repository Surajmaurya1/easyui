## Task

Install and integrate the EasyUI Stacked Cards component into my project.

A responsive, scroll-driven stacking cards component built with Tailwind CSS and Framer Motion. Cards start aligned in a column and stack gracefully on scroll without hijacking page scrolling.

## Usage

Import path and example from component metadata:

```tsx
import { StackedCards } from "@/components/ui/StackedCards";

export function Demo() {
  return (
    <StackedCards
      cards={[
        {
          id: 1,
          title: "Annual letter 2025",
          description: "Explore the latest trends, insights, and stories.",
          image: "https://images.unsplash.com/photo-1497366811353-6870744d04b2",
          ctaLabel: "Read story",
        },
      ]}
    />
  );
}
```

Declared props:
- `cards` (StackedCard[]); default: defaultCards — Array of card objects with title, description, image, and optional CTA link
- `title` (string); default: undefined — Optional section heading title
- `subtitle` (string); default: undefined — Optional section description subtitle
- `className` (string); default: undefined — Optional custom Tailwind styling for the outer wrapper
