## Usage

Import path and example from component metadata:

```tsx
import { Stepper, StepPanels, type Step } from "@/components/ui/stepper";

const steps: Step[] = [
  { title: "Account", description: "Your details" },
  { title: "Workspace", description: "Name it" },
  { title: "Invite", description: "Optional" },
  { title: "Done" },
];

const [current, setCurrent] = React.useState(0);

<Stepper steps={steps} current={current} onStepChange={setCurrent} />
<StepPanels current={current}>
  <div>Step 1 content</div>
  <div>Step 2 content</div>
  <div>Step 3 content</div>
  <div>Step 4 content</div>
</StepPanels>
```

Declared props:
- `steps` (Step[]); default: undefined — List of steps with title and optional description
- `current` (number); default: 0 — Zero-based index of the active step
- `onStepChange` ((index: number) => void); default: undefined — Callback enabling jump-back clicks on completed steps
- `orientation` ('horizontal' | 'vertical'); default: 'horizontal' — Layout direction of the stepper line
- `className` (string); default: undefined — Additional CSS classes for the stepper container
