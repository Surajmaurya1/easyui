## Usage

Import path and example from component metadata:

```tsx
import { StretchSwitch } from "@/components/ui/stretch-switch";

export function Demo() {
  return (
    <div className="space-y-3 max-w-sm">
      <StretchSwitch
        label="Reduce motion"
        description="Disables parallax and large translations across the app."
        defaultChecked
      />
      <StretchSwitch
        label="Show pre-release features"
        description="Toggle to preview experiments in the dashboard."
      />
    </div>
  );
}
```

Declared props:
- `checked` (boolean); default: undefined — Controlled checked state
- `defaultChecked` (boolean); default: false — Initial checked state (uncontrolled)
- `disabled` (boolean); default: false — Prevents interaction
- `onChange` ((checked: boolean) => void); default: undefined — Called when the switch toggles
- `label` (React.ReactNode); default: undefined — Label text on the left
- `description` (string); default: undefined — Helper text below the label
