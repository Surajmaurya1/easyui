## Task

Install and integrate the EasyUI Traffic Card component into my project.

## Usage

Import path and example from component metadata:

```tsx
import { TrafficCard } from "@/components/ui/traffic-card";

const channels = [
  { id: "direct", label: "Direct" },
  { id: "referral", label: "Referral" },
  { id: "social", label: "Social" },
  { id: "search", label: "Search" },
  { id: "paid", label: "Paid" },
];

const ranges = [
  {
    id: "day",
    label: "Day",
    caption: "Last 22 days",
    points: [
      { label: "Oct 27", values: { direct: 210, referral: 340, social: 402, search: 268, paid: 246 } },
      { label: "Oct 28", values: { direct: 246, referral: 372, social: 438, search: 301, paid: 289 } },
      // …one point per column
    ],
  },
  {
    id: "week",
    label: "Week",
    caption: "Last 22 weeks",
    points: [
      { label: "Jun 22", values: { direct: 812, referral: 1290, social: 1520, search: 1040, paid: 960 } },
      // …one point per column
    ],
  },
];

export function Demo() {
  return (
    <div className="w-full max-w-[380px]">
      <TrafficCard channels={channels} ranges={ranges} />
    </div>
  );
}
```

Declared props:
- `ranges` (TrafficRange[]) — Switchable ranges, each with its own points, caption, and optional total
- `channels` (TrafficChannel[]) — Channel definitions rendered bottom-to-top in every stacked column
- `defaultRange` (string); default: first range — Range id selected on first render
- `onRangeChange` ((id: string) => void) — Called when the visitor switches the Day / Week control
- `title` (string); default: "Traffic" — Heading shown at the top of the card
- `unit` (string); default: "visits" — Noun displayed beside the headline number
- `format` ((n: number) => string); default: rounded Intl.NumberFormat — Formats the headline, tooltip values, and screen-reader table
- `height` (number); default: 132 — Chart height in pixels
- `animated` (boolean); default: true — Count-up and column entrance animations (disabled for reduced motion)
- `className` (string); default: "" — Additional CSS classes for the card
- `TrafficRange.points` (TrafficPoint[]) — One column per entry, ordered oldest to newest
- `TrafficPoint.values` (Record<string, number>) — Channel id → visits for that interval
- `TrafficChannel.color` (string) — Optional CSS color; defaults to the built-in traffic palette
