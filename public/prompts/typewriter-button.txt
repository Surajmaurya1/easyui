## Usage

Import path and example from component metadata:

```tsx
import { TypewriterButton } from "@/components/ui/typewriter-button";

export function Demo() {
  return (
    <div className="flex items-center gap-4">
      <TypewriterButton soundEnabled variant="primary">
        npm install @easyui/react
      </TypewriterButton>
    </div>
  );
}
```

Declared props:
- `children` (string) — Label text to type out
- `charDuration` (number); default: 75 — Milliseconds per character reveal
- `soundEnabled` (boolean); default: false — Enables mechanical keystroke sound cues
- `soundVolume` (number); default: 0.25 — Web Audio synthesizer output volume (0 to 1)
- `variant` ('primary' | 'secondary' | 'outline'); default: 'primary' — Styling appearance
- `autoStart` (boolean); default: false — Begins typing immediately upon mounting
- `onComplete` (() => void); default: undefined — Callback on typing completion
