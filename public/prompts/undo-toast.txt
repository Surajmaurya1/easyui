## Usage

Import path and example from component metadata:

```tsx
import { UndoToast } from "@/components/ui/undo-toast";

export function Demo() {
  const [show, setShow] = useState(true);

  return (
    <UndoToast
      open={show}
      title="File deleted"
      description="Item moved to trash"
      duration={5000}
      onUndo={() => console.log('Action reversed')}
      onDismiss={() => setShow(false)}
    />
  );
}
```

Declared props:
- `open` (boolean); default: true — Visibility state of the undo toast
- `title` (string); default: 'Project archived' — Primary notification message title
- `description` (string); default: 'Changes will be permanent in a few seconds' — Optional descriptive subtitle
- `undoLabel` (string); default: 'Undo' — Label for undo action trigger
- `restoredMessage` (string); default: 'Restored successfully' — Title displayed when action has been reversed
- `duration` (number); default: 5000 — Duration in milliseconds before auto-dismissal
- `variant` ('default' | 'success' | 'warning' | 'error' | 'info'); default: 'default' — Semantic visual tone
- `position` ('top-left' | 'top-center' | 'top-right' | 'bottom-left' | 'bottom-center' | 'bottom-right'); default: 'bottom-center' — Screen placement
- `onUndo` (() => void); default: undefined — Callback fired when user clicks Undo
- `onDismiss` (() => void); default: undefined — Callback fired when toast closes or expires
- `showProgress` (boolean); default: true — Whether to show the countdown bar
