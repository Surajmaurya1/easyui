## Usage

Import path and example from component metadata:

```tsx

export function Demo() {
  return (
    <div className="w-full py-12 flex justify-center">

```

Declared props:
- `accounts` (WalletAccount[]); default: DEFAULT_ACCOUNTS — Array of up to 3 accounts displaying logo, balance, and custom colors
- `visible` (boolean); default: undefined — Controlled visibility state for balances and cards
- `defaultVisible` (boolean); default: true — Uncontrolled initial visibility state
- `onVisibleChange` ((visible: boolean) => void); default: undefined — Callback fired when balance visibility is toggled
- `currency` (string); default: 'USD' — ISO currency symbol used for formatted card amounts
- `locale` (string); default: 'en-US' — Locale string for number formatting
- `totalLabel` (string); default: 'Total Balance' — Caption label displayed below the total balance figure
- `className` (string); default: '' — Optional CSS class overrides for the outer container
