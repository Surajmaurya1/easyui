## Usage

Import path and example from component metadata:

```tsx
import { WalletCard } from "@/components/ui/wallet-card";

export function Demo() {
  return (
    <div className="w-full max-w-md mx-auto">
      <WalletCard
        balance="$4,566.00"
        cardType="Mastercard"
        cardLastFour="3040"
        buttonLabel="Use Wallet"
        onUseWallet={() => console.log('wallet used')}
        balanceLabel="Total Balance"
      />
    </div>
  );
}
```

Declared props:
- `balance` (string); default: '$4,566.00' — Headline balance figure rendered as the dominant type
- `cardType` (string); default: 'Mastercard' — Card brand label shown in the subtitle
- `cardLastFour` (string); default: '3040' — Last four digits of the underlying card
- `buttonLabel` (string); default: 'Use Wallet' — Label for the primary action button
- `onUseWallet` (() => void); default: undefined — Click handler for the action button
- `disabled` (boolean); default: false — Disable the action button
- `balanceLabel` (string); default: 'Total Balance' — Small caption under the balance figure
- `className` (string); default: undefined — Additional Tailwind classes merged into the card root
